## 🛠️ What I'm building

- 🔍 **[Fraud Detection Pipeline](https://github.com/AvikSh14/fraud-detection-pipeline)** · a real time card fraud detection system built as small services. Kotlin services stream transactions through **Apache Kafka**, an **Apache Flink** job detects suspicious activity, and a **Spring Boot** service with **PostgreSQL** stores the alerts. Work in progress, built in the open.
